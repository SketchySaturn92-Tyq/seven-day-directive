# 七日指令 · THE SEVEN-DAY DIRECTIVE

一款赛博朋克权谋题材的单人卡牌生存游戏。纯前端，无依赖，打开 `index.html` 即可玩。

> 你是穹顶集团的中层。董事会把一副十二张「指令卡」推到你面前，**每七天必须折掉至少一张**——
> 在行动地图上找到对应城区的目标并完成它。**折完全部十二张，你活下来。** 期限归零，你被回收。

---

## 玩法

| 系统 | 说明 |
|---|---|
| 指令卡 | 12 张，折完通关。每折一张，期限重置为 7 天 |
| 四条路径 | 操控（紫）、资本（金）、扩张（青）、清洗（红） |
| 三个品级 | 黑铁 / 白银 / 曜金，级别必须与目标级别匹配 |
| 五属性 | 智慧、魅力、战斗、隐匿、体魄 |
| 名望四轨 | 忠诚（归零被清算）、声望、罪痕（满值被回收）、权柄 |
| 四名出身 | 合规部次长、灰市掮客、外勤队长、信息安全幽灵 |
| 十个城区 | 高塔商业区、交易所广场、研究所园区、下层居住区、工业港区、轨道港、环带维修层、记忆银行、回收场、穹顶之外 |
| 卡牌获取 | 开局只发三张。其余靠主线推进、人物关系、委托交差、事件选项、城区跑动逐张挣来；折不动时可花 2 点行动「申领」保底 |
| 判定 | 六级难度+目标抗性，减去属性、装备与权柄；可现金加注或投入芯片压低判定线 |
| 命运商店 | 局内打得好就多攒命运点，在主页换成永久强化，下一局开局生效。结算按表现给分：结局分量、委托交差、存活天数、认识的人、名望积累逐项计 |
| 存档续局 | 每次动作后自动写档，主页出现「继续上一局」，关掉页面也能接着玩 |
| 音效 | 12 个音效全部用 Web Audio 现场合成，不带素材文件 |
| 背景音乐 | Meowa 生成的循环音轨（约 3 分钟），淡入淡出，切后台暂停；与音效分开开关 |
| 地图指引 | 选中手牌后，从牌拉一条引线到目标城区，端点脉冲，目标节点同步点亮 |
| 结局图鉴 | 17 个结局按难度排开，见过的摊全文与后日谈，没见过的只留编号 |
| 键盘 | 1-9 选牌、Enter 投放、空格结束这一天、A/T/P/L 开面板、Esc 取消 |

内容体量：200 条事件、120 条委托、96 场 NPC 个人支线、9 场主线、17 个结局（各带后日谈）、32 条卡牌获取来源、80 条对话话题、64 条世界观碎片、10 张城区场景图。全部中文正文约 15.5 万字。

自检：`node scripts/verify.js`（数据层结构 + 事件门控 + 结算计分 + 平衡模拟 + 构建产物，37 项断言）。

## 操作

1. 主页点「开始新的牌局」，选一个出身。
2. 拖动底部手牌到地图上对应城区，或在城区详情里点「执行」。
3. 行动点用来进修、赚钱、收情报；花完就「结束这一天」，会触发一个事件。
4. 期限数字变红时就是在警告你：再不折牌就出局了。

├── index.html              页面骨架
├── style-v3.css            全部样式（含手机端适配）
├── build.sh                把 game/ 下的源码按依赖顺序拼成 bundle.js

    ├── story-npc-a2.js     支线续篇：A 组第 4-6 幕
    ├── story-npc-b2.js     支线续篇：B 组第 4-6 幕

    ├── event-gates.js      事件触发条件表：配重、出现窗口、折牌门槛、硬条件

引擎与界面分离：改玩法只动 `engine.js`，改数据只动 `data.js` / `content-*.js`，改外观只动 `style-v3.css`。**改完 `game/` 下任何 JS 都要重跑 `./build.sh`**，页面加载的是合并后的 `game/bundle.js`。

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

也可以直接双击 `index.html`。资源引用全部是相对路径，两种方式都可以。

## 加内容

新增事件：在 `game/content-extra.js` 里按现有结构往 `window.EVENTS_EXTRA` 追加。字段：

```js
{ id, portrait, district, title, text,
  options: [{ label, run: { money, intel, chips, gear, vitality, statRandom, track: { loyalty, renown, sin, power }, resetDeadline } }] }
```

新增结局：往 `window.ENDINGS_EXTRA2` 追加 `{ id, name, cond, text }`。判定按数组顺序命中第一个满足项，兜底结局始终在最后。
